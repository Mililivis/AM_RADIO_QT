# AM радіо на RTL-SDR (Qt6)

SDR-приймач з GUI для Raspberry Pi 5 + RTL-SDR Blog V4:

- **живий огляд** ефіру шириною до 2.4 МГц: спектр і **водоспад**, масштаб колесом миші;
- **панорама** діапазону будь-якої ширини (наприклад, увесь КХ 2–30 МГц) і пошук АМ-станцій;
- **АМ-приймач**: будь-яка станція всередині вікна, клік по спектру/водоспаду — слухати;
- **запис IQ** у файл (SigMF, бітова копія даних донгла) і відтворення записів;
- **передача IQ на інший хост** за протоколом rtl_tcp (SDR++, GQRX, SDR#, GNU Radio).

Спектр і водоспад показують **всю енергію**: кожен семпл (перекриття 75 %), нормування за Парсевалем,
кожен піксель = сума потужності своєї смуги частот. Подробиці і схема шарів —
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

Працює через SSH: вікно — X11-прокидання, звук — потік PCM по тому ж SSH.

## Встановлення з нуля (на Пі)

```bash
git clone https://github.com/Mililivis/AM_RADIO_QT.git ~/AM_RADIO_QT
cd ~/AM_RADIO_QT
./SDR/scripts/install_librtlsdr.sh            # librtlsdr з підтримкою V4 (rtl-sdr-blog), один раз
sudo apt install -y qt6-base-dev libpulse-dev libfftw3-dev
cmake -B build && cmake --build build -j4
./build/core_tests                            # перевірка ядра, донгл не потрібен
```

`libfftw3-dev` необов'язкова (без неї працює вбудоване FFT), але з нею навантаження на CPU нижче.

## Команди (на ноутбуці)

Зібрати / оновити на Пі:

```bash
~/AM_RADIO_QT/scripts/deploy.sh
```

Запустити (вікно і звук на ноутбуці, порт rtl_tcp прокинуто на ноутбук):

```bash
~/AM_RADIO_QT/scripts/run_remote.sh
```

Те саме вручну:

```bash
ssh -Y -C -L 1234:localhost:1234 mililivis@10.42.0.221 'cd ~/AM_RADIO_QT && QT_QPA_PLATFORM=xcb exec ./build/am_radio --audio-stdout' | pw-cat --playback --format s16 --rate 48000 --channels 1 --latency 100ms -
```

- `-Y` — X11-прокидання, `-C` — стиснення, `-L 1234:...` — тунель для rtl_tcp (SDR++ на ноутбуці → `localhost:1234`).
- `--audio-stdout` — звук (s16le, моно, 48 кГц) у stdout → SSH → `pw-cat`. Без нього звук іде на динамік Пі.

Опції програми:

| Опція | Що робить |
|---|---|
| `--tune 9615` | одразу слухати частоту, кГц |
| `--panorama 2300-26100` | одразу почати панораму діапазону, кГц |
| `--rtltcp 1234` | одразу запустити сервер rtl_tcp |
| `--file запис.sigmf-meta` | відтворювати IQ-запис замість донгла (усе працює, крім панорами) |
| `--device 1` | інший донгл |

## Користування

**Огляд ефіру.** «Старт огляду» — безперервний захоплення вікна навколо «Центру».
«Ширина вікна» — 288 кГц … 2.4 МГц. «Водоспад» — ліній за секунду (усі семпли між лініями усереднюються).
На спектрі і водоспаді: **колесо** — масштаб, **перетягування** — зсув, **клік** — слухати цю частоту,
**подвійний клік** — показати все вікно.

**АМ-приймач.** Частота може бути будь-де у вікні — донгл не перебудовується; якщо частота поза вікном,
вікно саме зсувається. «Смуга» — ширина фільтра каналу, ◀ ▶ — сусідні знайдені станції.

**Панорама і пошук станцій.** «Знайти станції» — один ретельний прохід діапазону з пошуком несучих.
«Панорама ⟳» — безперервні проходи, кожен прохід = рядок водоспаду; діапазон будь-якої ширини.
Клік по панорамі — перейти в живий огляд на цій частоті і слухати.

**Запис IQ** (вкладка). Пише все вікно огляду: `iq_<час>_<частота>Hz_<швидкість>sps.sigmf-data` (сирі cu8, як `rtl_sdr`)
+ `.sigmf-meta` (частота, час UTC, перебудови, втрати). 2.4 МГц = 4.8 МБ/с ≈ 17 ГБ/год.
Відкривається в inspectrum, GNU Radio, SDR++, URH або тут же: `--file`.

**Мережа** (вкладка). Сервер rtl_tcp: у SDR-програмі на іншому хості вибрати джерело *RTL-TCP*,
адреса `<IP Пі>:1234` (або `localhost:1234` через SSH-тунель), частота дискретизації = ширина вікна.
«Дозволити керування» — клієнт може змінювати частоту, ширину і підсилення.

## Проблеми

| Симптом | Що робити |
|---|---|
| `cannot connect to X server` | підключатися з `-Y`; на Пі в `/etc/ssh/sshd_config` має бути `X11Forwarding yes` |
| Вікно є, звуку немає | у рядку стану має бути «Звук: stdout», натиснута кнопка «Слухати», `pw-cat` запущений |
| Водоспад гальмує через SSH | «Водоспад: 5 ліній/с», менше вікно програми |
| Звук переривається | збільшити `--latency 300ms` у `pw-cat` |
| Станцій не знайдено | антена, більше підсилення, менший поріг. СХ краще чути ввечері/вночі |
| Запис: «втрачено N семплів» | карта пам'яті не встигає: менша ширина вікна або швидший носій |
| `Failed to open RTL-SDR ... busy` | донгл зайнятий іншою програмою (rtl_test, rtl_tcp, другий am_radio) |
